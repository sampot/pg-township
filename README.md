# 潮生鎮誌（`pg-township`）

七日採訪行程、對話選項、早市贈禮——好感與共同記憶決定多種結局。

類型：**視覺小說／敘事經營** · 系列：懷舊

## 遊玩

純 HTML／CSS／JavaScript（無 build）。在 Playgrounds 畫布或 go 純玩版開啟 `index.html`。

- 每日 **上午／下午** 各安排一項行程
- 採訪三位鎮民時選擇對話；可贈送早市禮物
- 第七夜依好感、旗標與共同記憶進入不同結局（可勝可敗）
- 進度走宿主 **`PG.kv`**

## 開發

```bash
npx vitest run
```

Agent 契約見 Playgrounds 宿主 [`docs/PG-GAME-AGENT-GUIDE.md`](https://github.com/sampot/playgrounds/blob/main/docs/PG-GAME-AGENT-GUIDE.md)。
